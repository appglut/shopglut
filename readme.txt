Build and customize your WooCommerce store: product page, shop and archive, cart, checkout fields, thank you page, swatches, badges, filters, wishlist, side cart and popups.

== Description ==

**ShopGlut** is an all-in-one builder for WooCommerce. Instead of installing a separate plugin for every storefront feature, you manage the product page, shop, cart, checkout, wishlist and more from one modern admin.

= Modules =

* **Product Page Builder** - design single product pages with ready-made templates and live styling.
* **Shop & Archive Builder** - control the layout of the shop, category and tag pages.
* **Cart Page Builder** - create a cleaner, more convincing WooCommerce cart page.
* **Checkout Field Editor** - add, remove, reorder and edit checkout fields.
* **Thank You Page Builder** - customize the order complete page.
* **Variation Swatches** - show color, image and label swatches instead of dropdowns.
* **Product Badges** - add sale, new, hot and custom badges to products.
* **Shop Filters** - let shoppers filter products by category, price, attribute and more.
* **Wishlist** - let customers save products and come back later.
* **Side Cart** - slide-out mini cart with quick quantity changes and checkout button.
* **Popups & Banners** - promotional popups and banners for your store.

= Why ShopGlut =

* One plugin and one admin instead of many single-purpose plugins.
* Works with classic and block themes.
* Compatible with HPOS (High-Performance Order Storage).
* Assets load only on the pages where a module is used.
* Translation ready and RTL friendly.

= Requirements =

WooCommerce must be installed and active.

== Installation ==

1. Upload the plugin to `/wp-content/plugins/` or install it from the Plugins screen.
2. Activate WooCommerce, then activate ShopGlut.
3. Open the ShopGlut menu and enable the modules you need.

== Frequently Asked Questions ==

= Does ShopGlut require WooCommerce? =

Yes. WooCommerce must be installed and active.

= Can I use only some modules? =

Yes. Enable only the modules you need; unused modules load nothing on the front end.

= Does it work with block themes? =

Yes, it works with classic and block themes.
