# Photo Reviews: Feature Spec

- **ID**: `photo-reviews` · **Plugin**: ShopGlut · **Code**: `modules/photo-reviews/module.php`
- **Benchmarked against**: Customer Reviews for WooCommerce (80k), Revopic Photo Reviews (CodeCanyon 3.7k), WooCommerce Photo Reviews by VillaTheme

## Built (7 Nov)
- [x] Photos on the review form with a limit, size and type checks
- [x] Verified buyers only (option)
- [x] Photo strip above the reviews

## Free: full
- [ ] Photos open in a lightbox with next / previous
- [ ] Rating summary: average, bars per star (5★ 70%…), click a bar to filter
- [ ] Filter "with photos", sort by newest / highest / lowest / most helpful
- [ ] Review title field and "helpful" votes
- [ ] Photos saved in the Media Library, linked to the review; removed when the review is deleted
- [ ] Admin: photos shown in the comment edit screen, remove one photo
- [ ] Client-side resize before upload (max 1600px) to keep uploads small

## Pro
- [ ] Video reviews (MP4 up to a size limit)
- [ ] Review from email link without login (with BusinessGlut Review Reminders)
- [ ] Extra coupon for a photo review (BusinessGlut review coupons)
- [ ] Reviews wall / carousel shortcode for the home page
- [ ] Import reviews from CSV
- [ ] Review form fields: fit, quality, recommend yes/no

## Tests
- [ ] Upload 5 photos on mobile, HEIC refused with a clear message, block theme reviews
