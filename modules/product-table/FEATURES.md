# Product Table: Feature Spec

- **ID**: `product-table` · **Plugin**: ShopGlut · **Code**: `modules/product-table/module.php`
- **Benchmarked against**: WooCommerce Product Table by Barn2, Woo Product Table Pro (CodeCanyon 3.3k), Product Table for WooCommerce (5k)

## Built (7 Nov)
- [x] `[shopglut_product_table]` by category, tag or IDs
- [x] Each variation as its own row
- [x] Quantities and add many to cart at once

## Free: full
- [ ] Choose and order columns: image, name, SKU, price, stock, attributes, short description, categories, quantity, add to cart, tick box
- [ ] Settings page with defaults; shortcode attributes override them
- [ ] Sort by clicking a column header; search box above the table; pagination
- [ ] Filters above the table: category, in stock, on sale
- [ ] Variations as rows or as a dropdown in one row
- [ ] Add to cart by AJAX with a "added" message and cart fragments
- [ ] Mobile: rows become cards
- [ ] Gutenberg block

## Pro
- [ ] AJAX loading for big catalogs (server-side pages, search and sort)
- [ ] Custom field and product add-on columns
- [ ] Quick order form: type SKUs + quantities (B2B)
- [ ] Wholesale price column (BusinessGlut B2B)
- [ ] Table designs and colours
- [ ] Tables per user role
